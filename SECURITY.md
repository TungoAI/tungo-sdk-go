# Security policy

## Supported versions

Use the latest release of the Tungo SDK for Go. Fixes are published as new releases; upgrade before reporting a problem, it may already be fixed.

## Reporting a vulnerability

Report a vulnerability privately through support in the Tungo personal cabinet: https://app.tungo.kz. Do not report it publicly, for example in a GitHub issue or discussion.

Include the SDK version, the runtime version, and the smallest example that shows the problem. Never include a real API key, webhook secret or any other secret in a report.

If an API key was exposed, revoke it in the Tungo cabinet first, then report.

## Scope

This policy covers the code in this repository. Report a problem in the Tungo API itself the same way.
